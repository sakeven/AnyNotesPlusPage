## 자주 묻는 질문

**어떤 플랫폼을 지원하나요?**

iPhone, iPad와 네이티브 Mac 환경을 제공합니다. 기기 데이터 도구와 녹음 중 실시간 정리는 iOS 기능입니다. 자세한 차이는 사용 설명서에서 확인하세요.

**기기 간에 무엇이 동기화되나요?**

노트와 주제는 개인 iCloud로 동기화됩니다. 채팅 기록, AI 작업 공간 파일, Skills와 앱 도구 설정은 각 기기에 저장됩니다.

**녹음과 실시간 음성 대화는 어떻게 다른가요?**

녹음은 내 음성을 노트로 저장하며 API 키 모드에서는 실시간 정리도 가능합니다. 실시간 음성은 AI와 양방향으로 대화하며 기존 채팅을 이어 갈 수 있습니다.

**AI 기능에는 무엇이 필요한가요?**

iPhone과 iPad에는 AnyNotes Pro와 API 키 또는 Codex 로그인이 필요합니다. Mac 앱은 AnyNotes Pro가 필요하지 않습니다. AI 서비스 사용량은 별도로 적용되며 기능은 계정에 따라 달라집니다.

## AI Chat Linux Sandbox

AI Chat에는 기기에서 실행되는 Alpine Linux 에뮬레이터가 내장되어 있어 셸 명령과 스크립트로 파일 처리, 계산, 차트 및 문서 생성을 수행할 수 있습니다. 읽기 전용 터미널 패널에서 실행한 명령과 출력을 확인하고, 실행 중인 명령을 중지하며, 생성한 파일을 미리 보거나 공유할 수 있습니다. Linux 패키지 다운로드와 ZIP 파일 또는 GitHub를 통한 AI Skills 가져오기도 지원합니다. 설정의 도구 및 스킬 > Sandbox에서 로컬 작업 공간 저장 용량을 관리할 수 있습니다. AI 서비스와 다운로드에는 네트워크 연결이 필요합니다.

**어디에서 사용할 수 있나요?**

설정의 도구 및 스킬 > Sandbox에서 실행 환경과 작업 공간 상태를 확인하세요. AI Chat에서 Sandbox 명령 활동을 누르면 실행한 명령, 실시간 출력, 상태 및 실행 시간을 확인할 수 있습니다. 터미널 패널은 읽기 전용이며 작업은 AI Chat으로 요청합니다. 실행 중인 명령은 중지할 수 있습니다. 설정의 도구 및 스킬 > Skills에서 가져온 스킬과 스크립트를 관리할 수 있습니다.

**파일은 어디에 저장되며 정리하면 무엇이 삭제되나요?**

스크립트, 입력, 생성 파일 및 다시 열 수 있는 대화는 로컬 AI 작업 공간에 저장되며 iCloud로 동기화되지 않습니다. 작업 공간을 삭제하면 해당 파일과 저장된 대화가 삭제되지만 원본 노트나 Topic은 삭제되지 않습니다. Rootfs를 재설정하면 Linux 환경이 앱에 포함된 상태로 돌아가고 해당 환경의 변경 사항은 사라집니다.
