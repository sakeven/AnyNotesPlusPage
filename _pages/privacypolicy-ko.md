# AnyNotes+ 개인정보 처리방침

업데이트: 2026년 11월 12일

이 방침은 AnyNotes+ 앱과 확장 기능의 정보 처리 방식을 설명합니다. 사용할 수 있는 기능은 플랫폼과 앱 버전에 따라 다릅니다. 개발자는 Chong Jiang이며, 개인정보 관련 문의는 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com)으로 보내실 수 있습니다.

## 1. 콘텐츠와 저장

앱은 사용자가 작성하거나 가져오거나 사용하도록 요청한 콘텐츠를 처리합니다. 여기에는 노트, Topic, 태그, 링크, 녹음과 전사, 사진과 이미지, 문서, 채팅 메시지, AI 결과, 제목과 날짜 등의 관련 메타데이터가 포함됩니다.

노트, Topic 및 관련 미디어는 기기에 저장되며, iCloud를 사용할 수 있을 때 사용자의 비공개 Apple CloudKit 데이터베이스를 통해 동기화됩니다. 채팅 기록, 실시간 음성 기록, AI 작업 공간 파일, Skills, App Tool 설정 및 연결 환경설정은 기기에 보관되며 노트로 동기화되지 않습니다. 사용자가 대화 내용을 노트로 저장하면 해당 내용은 노트 저장 및 동기화 과정에 포함됩니다.

개발자는 노트 보관함을 저장하거나 AI 요청을 중계하는 중앙 서버를 운영하지 않습니다. 그렇다고 모든 처리가 기기 안에서 이루어지는 것은 아닙니다. 아래 기능을 사용하면 해당 서비스로 데이터가 전송됩니다. 시스템 백업 및 내보내거나 공유한 파일의 보관 기간은 별도로 관리됩니다.

## 2. AI 처리와 계정

AI 기능은 관련 노트나 Topic 내용, 대화 맥락, 첨부 파일 또는 추출한 파일 텍스트, 이미지, 오디오, 전사 및 도구 결과를 선택한 서비스로 보내 정리, 요약, 답변, 전사, 음성 처리 또는 콘텐츠 생성에 사용합니다. AI가 설정되어 사용 가능한 경우 새로 추가한 노트는 AI Inbox에서 자동 처리될 수 있습니다. 실시간 음성은 통화 중 마이크 오디오를 전송하며, 녹음 전사는 녹음 파일을 업로드할 수 있습니다. AI 도구는 요청 수행에 필요한 노트와 작업 공간 파일을 읽을 수 있습니다.

- **OpenAI API:** 입력한 API 키와 API Host를 사용합니다. 기본 Host에서는 OpenAI가 요청을 받습니다. 사용자 지정 Host에서는 해당 운영자가 요청과 API 키를 받으므로 신뢰할 수 있는 서비스를 선택하세요.
- **ChatGPT/Codex 로그인:** 인증과 AI 요청은 OpenAI 서비스로 전송됩니다. 앱은 연결을 유지하기 위해 반환된 세션 토큰과 이메일 주소, 계정 식별자, 요금제 등이 포함될 수 있는 계정 정보를 저장합니다. 별도의 AnyNotes 계정은 만들지 않습니다.
- **연결 정보:** API 키, 사용자 지정 Host, 선택 사항인 Jina 인증 정보 및 로그인 세션은 지원되는 확장 기능에서도 연결을 사용할 수 있도록 기기의 앱 또는 공유 App Group 설정에 저장됩니다. AnyNotes 계정 서버에는 저장하지 않습니다.

서비스 제공자는 제출한 콘텐츠와 IP 주소 같은 연결 정보를 받으며, 요청을 서비스 계정과 연결할 수 있습니다. 이후 처리는 각 서비스의 이용약관, 개인정보 처리방침, 계정 설정 및 보관 규칙에 따릅니다. AnyNotes는 전송한 콘텐츠가 즉시 삭제되거나 전혀 보관되지 않는다고 약속하지 않습니다. [OpenAI 개인정보 처리방침](https://openai.com/policies/privacy-policy/)과 사용하는 API 또는 ChatGPT 계정에 적용되는 약관, 또는 사용자 지정 서비스의 방침을 확인하세요.

## 3. 웹페이지 읽기와 연결 도구

링크를 읽으면 원본 웹사이트에 접속합니다. 직접 추출하지 못하면 `r.jina.ai`의 **Jina Reader**를 사용하여 경로와 쿼리 매개변수를 포함한 원본 페이지 URL을 전송할 수 있습니다. Jina API 키가 없어도 이 서비스를 사용할 수 있으며, 키를 설정했다면 요청 인증에 사용합니다. 비공개 액세스 토큰이나 해당 서비스에 제공하고 싶지 않은 정보가 포함된 URL은 제출하지 마세요. 추출한 페이지 본문은 AI 서비스로도 전송될 수 있습니다. [Jina 법률 및 개인정보 정보](https://jina.ai/legal/)를 확인하세요.

활성화한 App Tools, 가져온 단축어, Skills 및 샌드박스 명령은 작업에 필요한 앱, 웹사이트 또는 패키지 서비스에 접속할 수 있습니다. 작업 매개변수, 공유하기로 선택한 파일 및 도구가 반환한 데이터는 해당 서비스와 AI 서비스에서 처리될 수 있습니다. 실행 전에 도구 권한과 확인 화면을 검토하세요. 단축어를 가져와 AI로 분석할 때도 가져오기 확인 후 동작 정의가 선택한 AI 서비스로 전송됩니다.

## 4. 기기 권한

마이크 및 음성 인식 권한은 녹음, 받아쓰기, 실시간 음성에 사용됩니다. Apple 음성 인식은 시스템 설정과 이용 가능 여부에 따라 Apple 서비스를 사용할 수 있으며, 기기 내에서만 처리된다고 보장하지 않습니다.

선택적 기기 도구는 별도로 허용한 캘린더 일정 세부 정보, 미리 알림, 선택한 사진, 현재 위치 및 읽기 전용 HealthKit 걸음 수, 수면, 운동 데이터를 사용합니다. 해당 시스템 권한과 앱 내의 별도 AI 사용 허용이 필요합니다. 답변에 필요한 결과는 선택한 AI 서비스로 전송될 수 있습니다. 위치는 필요할 때만 확인하며 지속적으로 추적하지 않습니다. 건강 데이터가 포함된 대화는 기기에 보관되며, 앱은 이 대화를 iCloud 동기화 노트로 저장하는 기능을 비활성화합니다. 알람 및 타이머 도구는 AnyNotes에서 만든 알람을 관리하며 필요한 권한을 요청합니다. [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/)을 확인하세요.

## 5. 구매, 진단 및 지원

App Store 결제는 Apple이 처리합니다. 앱은 StoreKit 상품 및 검증된 거래 정보를 읽어 구독, 체험 및 구매 복원을 제공합니다. 개발자는 앱을 통해 결제 카드 세부 정보를 받지 않습니다.

선택적 진단 기능은 문제 해결 정보를 기기에 저장하며, 비공개 콘텐츠나 서비스 응답이 포함될 수 있습니다. 진단을 끄면 새 진단 기록은 중단되지만 기존 로그 파일은 삭제되지 않습니다. 지원 이메일이나 로그를 보내면 개발자는 발신 주소와 보낸 정보를 받아 답변 및 조사에 사용합니다. 앱 콘텐츠를 판매하거나 광고에 사용하지 않습니다.

## 6. 선택, 보관 및 삭제

- AI 계정을 연결하지 않아도 수동 노트 기능을 사용할 수 있습니다. 새로운 iOS 구독 화면은 AI 데이터 공유를 설명하며, 신규 체험이나 구매 시작 전에 사용자의 명시적 동의를 요구합니다. 기기 데이터 권한은 별도로 허용해야 합니다.
- 연결을 통한 이후 AI 요청을 중단하려면 AI 서비스 설정에서 ChatGPT/Codex에서 로그아웃하거나 해당 API 키를 삭제하세요. 진행 중인 음성 세션이나 생성 작업도 종료하세요. 인증 방식을 전환하는 것만으로는 다른 방식의 저장된 인증 정보가 삭제되지 않습니다.
- **설정 → 데이터 사용**에서 선택적 기기 소스를 끄고 iOS 설정에서 시스템 권한을 취소할 수 있습니다. URL을 웹 읽기 서비스에 보내고 싶지 않으면 웹 읽기 작업을 중단하세요. 권한 취소는 이후 사용을 중단하지만 이미 전송한 데이터는 회수하지 못합니다.
- 노트와 Topic은 삭제할 때까지 기기와 iCloud에 보관됩니다. 클라우드 삭제에는 동기화가 성공해야 합니다. 오프라인 기기에는 동기화될 때까지 사본이 남을 수 있습니다. 앱만 삭제해도 iCloud 보관함은 삭제되지 않습니다.
- 채팅 기록과 작업 공간은 각각의 앱 내 기능으로 삭제하며 노트 삭제와 별개입니다. 원본 노트나 대화를 삭제해도 내보낸 파일, 공유한 사본 및 시스템 백업은 삭제되지 않습니다. 키와 세션은 설정에서 삭제하거나 해당 앱 데이터를 삭제할 때까지 남습니다.
- AnyNotes에서 콘텐츠를 삭제하거나 로그아웃해도 OpenAI, 사용자 지정 서비스, Jina 또는 Apple 계정이나 해당 서비스가 이미 보유한 데이터는 삭제되지 않습니다. 보관 및 삭제 방법은 각 서비스의 설정이나 문의 창구를 이용하세요. 개발자의 지원 이메일로 보낸 정보에 대한 접근이나 삭제는 이메일로 요청할 수 있습니다. 법적 의무를 이행하기 위해 일부 정보를 보관해야 할 수 있습니다.

## 7. 보안 및 방침 변경

앱은 운영체제의 저장 보호 기능과 각 서비스의 연결 보안을 사용합니다. 기본 AI 및 Jina 주소는 HTTPS를 사용합니다. 사용자 지정 주소의 보안과 데이터 처리는 설정 및 해당 운영자에 따라 다릅니다. 완전한 보안을 보장할 수 있는 시스템은 없습니다.

처리 방식이 바뀌면 이 페이지를 업데이트하며, 위 날짜가 해당 버전을 나타냅니다. 앱의 구독 화면과 웹사이트 하단에서 이 방침을 열 수 있습니다. 문의 사항은 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com)으로 보내세요.
