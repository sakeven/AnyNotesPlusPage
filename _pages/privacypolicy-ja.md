# AnyNotes+ プライバシーポリシー

更新日：2026年11月12日

本ポリシーは、AnyNotes+ アプリと拡張機能での情報の取り扱いを説明します。利用できる機能はプラットフォームとアプリのバージョンによって異なります。開発者は Chong Jiang です。プライバシーに関するお問い合わせは [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com) までお寄せください。

## 1. コンテンツと保存

アプリは、作成、読み込み、または使用を指示されたコンテンツを扱います。これには、ノート、Topic、タグ、リンク、録音と文字起こし、写真と画像、文書、チャットメッセージ、AI の結果、タイトルや日付などの関連メタデータが含まれます。

ノート、Topic、関連メディアは端末に保存され、iCloud が利用可能な場合は個人の Apple CloudKit データベースを通じて同期されます。チャット履歴、ライブ音声履歴、AI ワークスペースのファイル、Skills、App Tool 設定、接続設定は端末に保存され、ノートとしては同期されません。チャットの内容を明示的にノートとして保存した場合は、ノートの保存・同期の対象になります。

開発者は、ノートライブラリを保存したり AI リクエストを中継したりする中央サーバーを運営していません。ただし、すべての処理が端末内で行われるわけではなく、以下の機能では各サービスにデータが送信されます。システムのバックアップや書き出し・共有したファイルの保存期間は、それぞれ別に管理されます。

## 2. AI 処理とアカウント

AI 機能は、関連するノートや Topic の内容、会話の文脈、添付ファイルや抽出したテキスト、画像、音声、文字起こし、ツールの結果を選択したサービスへ送り、整理、要約、回答、文字起こし、音声処理、コンテンツ生成に使用します。AI が設定され利用可能な場合、新しく取り込んだノートは AI Inbox で自動処理されることがあります。ライブ音声では通話中のマイク音声を送信し、録音の文字起こしでは録音データをアップロードする場合があります。AI ツールは依頼の実行に必要なノートやワークスペースのファイルを読み取れます。

- **OpenAI API：** 入力した API キーと API Host を使用します。既定の Host では OpenAI が受信します。カスタム Host では、その運営者にリクエストと API キーが送信されます。信頼できるサービスを選択してください。
- **ChatGPT/Codex ログイン：** 認証と AI リクエストは OpenAI のサービスへ送信されます。接続を維持するため、返されたセッショントークンと、メールアドレス、アカウント識別子、プランなどを含むアカウント情報を保存します。別の AnyNotes アカウントを作成する必要はありません。
- **接続情報：** API キー、カスタム Host、任意の Jina 認証情報、ログインセッションは、対応する拡張機能でも利用できるよう、端末内のアプリまたは共有 App Group の設定に保存します。AnyNotes のアカウントサーバーには保存しません。

サービスは送信した内容と IP アドレスなどの接続情報を受信し、リクエストをサービス側のアカウントと関連付ける場合があります。その後の処理は、各サービスの利用規約、プライバシーポリシー、アカウント設定、保持規則に従います。AnyNotes は、送信内容が直ちに削除されることや、保持されないことを保証しません。[OpenAI のプライバシーポリシー](https://openai.com/policies/privacy-policy/)と利用する API または ChatGPT アカウントに適用される規約、またはカスタムサービスのポリシーをご確認ください。

## 3. ウェブページの読み取りと接続ツール

リンクを読み取ると、リンク先のウェブサイトに接続します。直接抽出できない場合、`r.jina.ai` の **Jina Reader** を利用し、パスとクエリパラメータを含む元のページ URL を送信する場合があります。Jina API キーが未設定でも利用されることがあり、設定されている場合はリクエストの認証に使用します。秘密のアクセストークンや、このサービスに渡したくない情報を含む URL は送信しないでください。抽出した本文は AI サービスにも送信される場合があります。[Jina の法務・プライバシー情報](https://jina.ai/legal/)をご確認ください。

有効にした App Tools、読み込んだショートカット、Skills、サンドボックスのコマンドは、作業に必要なアプリ、ウェブサイト、パッケージ配布サービスへ接続する場合があります。操作の引数、共有を選択したファイル、ツールが返すデータは、これらのサービスと AI サービスで処理される場合があります。実行前にツールの権限と確認画面をご確認ください。ショートカットを読み込んで AI で分析する場合も、読み込み確認後に動作定義を選択した AI サービスへ送信します。

## 4. 端末の権限

マイクと音声認識の権限は、録音、音声入力、ライブ音声に使用します。Apple の音声認識はシステム設定や利用状況に応じて Apple のサービスを使う場合があり、端末内だけでの処理は保証されません。

任意の端末ツールは、個別に許可されたカレンダーの予定詳細、リマインダー、選択した写真、現在地、読み取り専用の HealthKit の歩数・睡眠・ワークアウトを利用します。システム権限と、アプリ内での個別の AI 利用許可が必要です。回答に必要な結果を選択した AI サービスへ送信する場合があります。位置情報は必要なときだけ取得し、継続的には追跡しません。健康データを含む会話は端末に保存し、iCloud 同期ノートとしての保存をアプリで無効にしています。アラームとタイマーのツールは AnyNotes で作成したアラームを管理し、必要な権限を求めます。[Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/)をご確認ください。

## 5. 購入、診断、サポート

App Store の支払いは Apple が処理します。アプリは StoreKit の製品情報と検証済み取引情報を読み取り、サブスクリプション、トライアル、購入の復元を提供します。開発者がアプリを通じてカードの詳細を受け取ることはありません。

任意の診断機能は、問題調査の情報を端末に保存します。個人情報やサービスの応答が含まれる場合があります。診断を無効にすると新しい診断記録は停止しますが、既存のログは削除されません。サポートメールやログを送信した場合、開発者は送信元アドレスと送信内容を受け取り、返信と調査に使用します。アプリ内のコンテンツを販売したり、広告に使用したりすることはありません。

## 6. 選択、保持、削除

- AI アカウントを接続しなくても手動のノート機能を利用できます。新しい iOS サブスクリプション画面は AI データ共有を説明し、新規トライアルや購入の開始前に明示的な同意を求めます。端末データの許可は別途必要です。
- 接続先への以後の AI リクエストを停止するには、AI サービス設定で ChatGPT/Codex からログアウトするか、対応する API キーを削除してください。進行中の音声セッションや生成も終了してください。認証方式を切り替えるだけでは、もう一方の保存済み認証情報は削除されません。
- **設定 → データ利用**で任意の端末データを無効にし、iOS 設定でもシステム権限を取り消せます。URL をウェブ読み取りサービスに送信したくない場合は、ウェブ読み取り操作を停止してください。許可の取り消しは以後の利用を停止しますが、送信済みのデータは回収できません。
- ノートと Topic は、削除するまで端末と iCloud に保持されます。クラウドでの削除には同期の成功が必要です。オフラインの端末には同期までコピーが残る場合があります。アプリを削除するだけでは iCloud のライブラリは削除されません。
- チャット履歴とワークスペースは、それぞれのアプリ内の操作で削除します。ノートの削除とは別です。元のノートや会話を削除しても、書き出したファイル、共有済みのコピー、システムのバックアップは削除されません。キーとセッションは、設定で削除するか該当するアプリデータを削除するまで残ります。
- AnyNotes での削除やログアウトは、OpenAI、カスタムサービス、Jina、Apple のアカウントや、それらが保持するデータの削除にはなりません。保持や削除については、各サービスの設定や窓口をご利用ください。開発者のサポート窓口に送った情報へのアクセスや削除は、メールでご依頼いただけます。法的義務を果たすため、一部情報の保持が必要な場合があります。

## 7. セキュリティとポリシーの変更

アプリは OS の保存保護機能と各サービスの接続保護を使用します。既定の AI と Jina の接続先は HTTPS を使用します。カスタム接続先の安全性やデータの取り扱いは、その設定と運営者に依存します。完全な安全性を保証できるシステムはありません。

取り扱いに変更があれば本ページを更新し、上記の日付で版を示します。アプリのサブスクリプション画面やウェブサイトのフッターから閲覧できます。ご質問は [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com) までお寄せください。
