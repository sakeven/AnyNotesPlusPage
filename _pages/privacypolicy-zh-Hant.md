# AnyNotes+ 隱私權政策

更新日期：2026 年 11 月 12 日

本政策說明 AnyNotes+ 應用程式及擴充功能如何處理資訊。可用功能取決於平台與應用程式版本。開發者為 Chong Jiang；隱私問題可透過 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com) 聯絡。

## 1. 內容與儲存

本應用程式會處理你建立、匯入或要求使用的內容：筆記、Topic、標籤、連結、錄音與轉寫、照片與圖片、文件、聊天訊息、AI 結果，以及標題、日期等相關中繼資料。

筆記、Topic 及相關媒體儲存在裝置上，並在 iCloud 可用時透過你的私人 Apple CloudKit 資料庫同步。聊天記錄、即時語音歷史、AI 工作區檔案、Skills、App Tool 設定和連線偏好儲存在裝置上，不作為筆記同步。你主動將聊天內容儲存為筆記後，該內容會進入筆記儲存和同步流程。

我們不營運用於儲存你的筆記庫或中轉 AI 請求的集中式伺服器。這不代表所有處理都在本機完成：使用下述功能時，相應服務會接收資料。系統備份及你匯出或分享的檔案有各自的保留週期。

## 2. AI 處理與帳號

AI 功能會將相關筆記或 Topic 內容、對話上下文、附件或擷取出的檔案文字、圖片、音訊、轉寫及工具結果傳送給你選擇的服務，用於整理、摘要、回答、轉寫、語音或內容產生。設定並啟用可用的 AI 後，新增筆記可能由 AI Inbox 自動處理。即時語音會在通話期間傳送麥克風音訊；錄音轉寫可能上傳錄製的音訊。AI 工具可以讀取完成請求所需的筆記和工作區檔案。

- **OpenAI API：** 使用你填寫的 API Key 和 API Host 發出請求。預設 Host 的接收方為 OpenAI；自訂 Host 會讓其營運方收到請求和 API Key，請選擇你信任的服務。
- **ChatGPT/Codex 登入：** 驗證和 AI 請求傳送至 OpenAI 服務。應用程式儲存傳回的工作階段權杖及帳號資訊，其中可能包括電子郵件、帳號識別碼和方案，用於維持連線。你無需另外註冊 AnyNotes 帳號。
- **連線憑證：** API Key、自訂 Host、選用的 Jina 憑證和登入工作階段儲存在本機應用程式或共用 App Group 設定中，供支援的擴充功能使用。我們不會將其存入 AnyNotes 帳號伺服器。

服務方會接收提交的內容及 IP 位址等連線資訊，並可能將請求與你的服務帳號關聯。其服務條款、隱私權政策、帳號設定及保留規則決定後續處理；AnyNotes 不承諾傳輸內容會被立即刪除或絕不保留。請參閱 [OpenAI 隱私權政策](https://openai.com/policies/privacy-policy/)及適用於你所用 API 或 ChatGPT 帳號的條款，或自訂服務方的政策。

## 3. 網頁讀取與連接的工具

讀取連結會存取來源網站。如果直接擷取失敗，應用程式可能使用 `r.jina.ai` 的 **Jina Reader**，傳送來源網頁網址，包括路徑和查詢參數。未填寫 Jina API Key 時也可能使用該服務；如已填寫，則用於請求驗證。請勿提交含有私密存取權杖或不希望該服務接收的資訊的網址。擷取出的網頁正文還可能傳送給 AI 服務。請參閱 [Jina 法律與隱私資訊](https://jina.ai/legal/)。

啟用的 App Tools、匯入的捷徑、Skills 和沙箱命令可能存取任務所需的應用程式、網站或套件服務。操作參數、你選擇分享的檔案及工具傳回的資料，可能由這些服務和 AI 服務處理。執行操作前請查看工具權限與確認畫面。匯入捷徑並使用 AI 分析時，也會在匯入確認後將動作定義傳送給所選 AI 服務。

## 4. 裝置權限

麥克風與語音辨識權限用於錄音、聽寫和即時語音。Apple 語音辨識可能依系統設定及可用性使用 Apple 服務，並不保證全部在裝置本機完成。

選用裝置工具使用個別授權的行事曆事件詳情、提醒事項、選定照片、目前位置，以及唯讀的 HealthKit 步數、睡眠和體能訓練資料。這些功能需要相應系統權限及應用程式內的獨立 AI 使用授權；回答請求所需的結果可能傳送給所選 AI 服務。位置僅在需要時取得，不持續追蹤。涉及健康資料的聊天儲存在本機，應用程式禁止將這些對話儲存為 iCloud 同步筆記。鬧鐘與計時器工具管理 AnyNotes 建立的鬧鐘，並要求相應權限。請參閱 [Apple 隱私權政策](https://www.apple.com/legal/privacy/)。

## 5. 購買、診斷與支援

App Store 付款由 Apple 處理。應用程式讀取 StoreKit 商品和已驗證交易資訊，提供訂閱、試用與回復購買功能；我們不會透過應用程式取得你的信用卡詳情。

選用診斷功能將疑難排解資訊儲存在本機，可能包含私密內容或服務回應。關閉診斷會停止新增診斷記錄，但不會刪除既有日誌。如果你傳送支援郵件或分享日誌，我們會收到你傳送的地址及資訊，並用於回覆和排查。我們不會出售你的應用程式內容，也不會將其用於廣告。

## 6. 選擇、保留與刪除

- 不連接 AI 帳號也可以使用手動筆記功能。新版 iOS 訂閱頁說明 AI 資料分享，並要求使用者主動同意後才能開始新的試用或購買；裝置資料權限仍個別授權。
- 如需停止某個連線的後續 AI 請求，請在 AI 服務設定中登出 ChatGPT/Codex 或移除對應 API Key，同時結束正在進行的語音或產生任務。僅切換驗證模式不會清除另一種模式已儲存的憑證。
- 可在**設定 → 資料使用**關閉選用裝置來源，並在 iOS 設定中撤銷系統權限。如不希望將網址傳送給網頁讀取服務，請停止使用網頁讀取操作。撤銷只停止後續使用，無法收回已傳送的資料。
- 筆記與 Topic 在你刪除前保留於本機和 iCloud。雲端刪除需要成功同步；離線裝置可能保留副本直到完成同步。僅刪除應用程式不會刪除 iCloud 筆記庫。
- 聊天歷史與工作區可透過相應應用程式控制項刪除，與筆記刪除獨立。刪除原筆記或聊天不會刪除匯出檔案、已分享副本及系統備份。金鑰與工作階段會保留至你在設定中移除或刪除相應應用程式資料。
- 在 AnyNotes 刪除內容或登出，不會刪除你的 OpenAI、自訂服務、Jina 或 Apple 帳號，也不會刪除它們已持有的資料。其保留與刪除方式請使用服務方的控制選項或向其諮詢。對於傳送至我們支援信箱的資訊，可聯絡我們請求存取或刪除；為履行法律義務，部分資訊可能需要繼續保留。

## 7. 安全與政策變更

應用程式使用作業系統的儲存保護及服務提供的連線安全機制。預設 AI 與 Jina 位址使用 HTTPS；自訂位址的安全及資料處理取決於你的設定和服務方。任何系統都無法保證絕對安全。

處理方式變更時，我們會更新本頁，上方日期標示本版本。可從應用程式訂閱頁和網站頁尾開啟本政策，或透過 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com) 諮詢。
