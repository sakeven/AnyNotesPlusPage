# AnyNotes+ 隐私政策

更新日期：2026 年 11 月 12 日

本政策说明 AnyNotes+ 应用及扩展如何处理信息。可用功能取决于平台与应用版本。开发者为 Chong Jiang；隐私问题可通过 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com) 联系。

## 1. 内容与存储

本应用会处理你创建、导入或要求使用的内容：笔记、Topic、标签、链接、录音与转写、照片与图片、文档、聊天消息、AI 结果，以及标题、日期等相关元数据。

笔记、Topic 及关联媒体保存在设备上，并在 iCloud 可用时通过你的私人 Apple CloudKit 数据库同步。聊天记录、实时语音历史、AI 工作区文件、Skills、App Tool 配置和连接偏好保存在设备上，不作为笔记同步。你主动将聊天内容保存为笔记后，该内容会进入笔记存储和同步流程。

我们不运营用于保存你的笔记库或中转 AI 请求的集中式服务器。这不意味着所有处理都在本机完成：使用下述功能时，相应服务会接收数据。系统备份以及你导出或分享的文件有各自的保存周期。

## 2. AI 处理与账号

AI 功能会将相关笔记或 Topic 内容、对话上下文、附件或提取出的文件文本、图片、音频、转写及工具结果发送给你选择的服务，用于整理、总结、回答、转写、语音或内容生成。配置并启用可用的 AI 后，新增笔记可能由 AI Inbox 自动处理。实时语音会在通话期间发送麦克风音频；录音转写可能上传录制的音频。AI 工具可以读取完成请求所需的笔记和工作区文件。

- **OpenAI API：** 使用你填写的 API Key 和 API Host 发出请求。默认 Host 的接收方为 OpenAI；自定义 Host 会让其运营方收到请求和 API Key，请选择你信任的服务。
- **ChatGPT/Codex 登录：** 认证和 AI 请求发送至 OpenAI 服务。应用保存返回的会话令牌及账号信息，其中可能包括邮箱、账号标识和套餐，用于维持连接。你无需另行注册 AnyNotes 账号。
- **连接凭据：** API Key、自定义 Host、可选的 Jina 凭据和登录会话保存在本机应用或共享 App Group 设置中，供支持的扩展使用。我们不会将其存入 AnyNotes 账号服务器。

服务方会接收提交的内容及 IP 地址等连接信息，并可能将请求与你的服务账号关联。其服务条款、隐私政策、账号设置及保留规则决定后续处理；AnyNotes 不承诺传输内容会被立即删除或绝不保留。请参阅 [OpenAI 隐私政策](https://openai.com/policies/privacy-policy/)及适用于你所用 API 或 ChatGPT 账号的条款，或自定义服务方的政策。

## 3. 网页读取与连接的工具

读取链接会访问源网站。如果直接提取失败，应用可能使用 `r.jina.ai` 的 **Jina Reader**，发送源网页网址，包括路径和查询参数。未填写 Jina API Key 时也可能使用该服务；如已填写，则用于请求认证。请勿提交含有私密访问令牌或不希望该服务接收的信息的网址。提取出的网页正文还可能发送给 AI 服务。请参阅 [Jina 法律与隐私信息](https://jina.ai/legal/)。

启用的 App Tools、导入的快捷指令、Skills 和沙箱命令可能访问任务所需的应用、网站或软件包服务。操作参数、你选择分享的文件及工具返回的数据，可能由这些服务和 AI 服务处理。执行操作前请查看工具权限与确认界面。导入快捷指令并使用 AI 分析时，也会在导入确认后将动作定义发送给所选 AI 服务。

## 4. 设备权限

麦克风与语音识别权限用于录音、听写和实时语音。Apple 语音识别可能依系统设置及可用性使用 Apple 服务，并不保证全部在设备本地完成。

可选设备工具使用单独授权的日历事件详情、提醒事项、选定照片、当前位置，以及只读的 HealthKit 步数、睡眠和体能训练数据。这些功能需要相应系统权限及应用内的独立 AI 使用授权；回答请求所需的结果可能发送给所选 AI 服务。位置仅在需要时获取，不持续追踪。涉及健康数据的聊天保存在本机，应用禁止将这些对话保存为 iCloud 同步笔记。闹钟与计时器工具管理 AnyNotes 创建的闹钟，并要求相应权限。请参阅 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。

## 5. 购买、诊断与支持

App Store 支付由 Apple 处理。应用读取 StoreKit 商品和已验证交易信息，提供订阅、试用与恢复购买功能；我们不会通过应用获取你的银行卡详情。

可选诊断功能将排查信息保存在本机，可能包含私密内容或服务响应。关闭诊断会停止新增诊断记录，但不会删除已有日志。如果你发送支持邮件或分享日志，我们会收到你发送的地址及信息，并用于回复和排查。我们不会出售你的应用内容，也不会将其用于广告。

## 6. 选择、保留与删除

- 不连接 AI 账号也可以使用手动笔记功能。新版 iOS 订阅页说明 AI 数据共享，并要求用户主动同意后才能开始新的试用或购买；设备数据权限仍单独授权。
- 如需停止某个连接的后续 AI 请求，请在 AI 服务设置中退出 ChatGPT/Codex 或移除对应 API Key，同时结束正在进行的语音或生成任务。仅切换认证模式不会清除另一种模式已保存的凭据。
- 可在**设置 → 数据使用**关闭可选设备来源，并在 iOS 设置中撤销系统权限。如不希望将网址发送给网页读取服务，请停止使用网页读取操作。撤销只停止后续使用，无法收回已经发送的数据。
- 笔记与 Topic 在你删除前保留于本地和 iCloud。云端删除需要成功同步；离线设备可能保留副本直到完成同步。仅删除应用不会删除 iCloud 笔记库。
- 聊天历史与工作区可通过相应应用控件删除，与笔记删除独立。删除原笔记或聊天不会删除导出文件、已分享副本及系统备份。密钥与会话会保留至你在设置中移除或删除相应应用数据。
- 在 AnyNotes 删除内容或退出登录，不会删除你的 OpenAI、自定义服务、Jina 或 Apple 账号，也不会删除它们已持有的数据。其保留与删除方式请使用服务方的控制选项或向其咨询。对于发送至我们支持邮箱的信息，可联系我们请求访问或删除；为履行法律义务，部分信息可能需要继续保留。

## 7. 安全与政策变更

应用使用操作系统的存储保护及服务提供的连接安全机制。默认 AI 与 Jina 地址使用 HTTPS；自定义地址的安全及数据处理取决于你的配置和服务方。任何系统都无法保证绝对安全。

处理方式变化时，我们会更新本页，上方日期标识本版本。可从应用订阅页和网站页脚打开本政策，或通过 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com) 咨询。
