# 録音とリアルタイム整理

{% include guide-screens.html group='recording' %}

1. 録音を開始します。特定のプロジェクトなら、そのトピック内から始めます。
2. API キーモードでは「リアルタイム整理」と文字起こし原文を切り替え、要点、未解決の問い、次のステップを確認します。
3. 「考えるヒント」で提案を求められます。提案と原文は別に表示され、録音中の整理は暫定版です。
4. 操作の提案を確認すると録音が一時停止します。タイトル、日時、通知、アプリ操作を編集し、確認してから実行します。
5. 手動で録音を再開するか、完了して保存します。保存後には録音全体の文字起こしと整理も行われます。

> この議論の決定事項、未解決の問題、アクションをまとめて。担当者は明示されている場合だけ記載して。

リアルタイム整理には API キーが必要です。Codex ログインでも録音と保存後の文字起こしは利用できます。切断時は録音画面で再接続し、処理済みの範囲を確認してください。提案の表示や録音の完了だけでは操作は実行されません。確認済みの外部操作は録音を取り消しても元に戻りません。
