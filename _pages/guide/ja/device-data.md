# 予定・リマインダー・今日の進捗

iOS の「設定 > データの使用」で情報源ごとに許可します。必要に応じてシステム権限も求められます。

{% include guide-screens.html group='device' %}

- 「明日の予定を調べて、レビュー準備の時間を探して。」
- 「明日15時に資料送付をリマインドして。期限と同時に通知して。」
- 「今調べたレビューを16時に変更し、他の内容は維持して。」
- 「25分の集中タイマーを開始して。」

予定、リマインダー、アラームへの書き込みは、対象、内容、時刻、通知を確認した後に反映されます。期限と通知時刻は別なので、通知が必要なら明示してください。

今日の進行提案は、ノートやトピックの変化、別途利用を許可した予定・リマインダーから次に取り組む項目を提示します。当日の提案を無視したり、設定で表示を止めたりできます。

予定とリマインダーは1回につき最大31日分を検索でき、リマインダーの対象は未完了の項目です。アラームは AnyNotes が作ったものだけを扱い、システムの「時計」は読み取れません。写真は許可範囲、日付、文字認識で検索します。健康は歩数・睡眠・ワークアウトの読み取りのみ。位置情報は前面での単発取得です。健康データを含む会話は同期ノートに保存できません。
