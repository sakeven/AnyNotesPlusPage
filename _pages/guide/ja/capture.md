# テキスト・画像・ファイルの取り込み

{% include guide-screens.html group='capture' %}

| 内容 | 開始する場所 | できること |
| --- | --- | --- |
| アイデア、タスク、メモ | ノート | 整理、原文の編集、トピックへの追加 |
| 写真、スクリーンショット、紙の資料 | 読み込みからカメラ・写真 | 内容を認識し、画像について質問 |
| PDF、テキスト資料 | 読み込みからファイル | 原本を保存し、プレビュー・共有・AI 整理 |
| 口述、会議、インタビュー | ホームまたはトピックの録音 | 文字起こしと整理を経てノートに保存 |
| Webページや他のアプリの内容 | 共有シートの AnyNotes | AI 受信トレイに集約 |
| 考えたい問い | チャット | 話し合って必要な時にノートとして保存 |
| すぐ記録したい思いつき | ウィジェットや Quick Capture | アプリの入力画面を直接開く |

ファイルノートは PDF、TXT、MD、Markdown に対応し、1ファイル50 MBまでです。録音は一時停止を除いて合計1時間まで。ウィジェットはアプリを開いて入力する入口です。

タイトル、本文、タグ、AI 結果で検索でき、`#タグ` でも探せます。重要なノートはピン留めし、今使わないものはアーカイブできます。
