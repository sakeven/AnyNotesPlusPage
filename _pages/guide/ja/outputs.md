# ファイル・画像・Skills

AI Chat に資料を添付し、成果、形式、用途を指定します。

{% include guide-screens.html group='outputs' %}

- 「このノートからプロジェクトのブリーフを作り、結論と未確認事項を共有できるファイルにして。」
- 「このデータの月別合計を計算し、グラフと結果ファイルを作って。」
- 「このトピックを初めて読む人向けの知識カードにして。」
- 「画像の内容と構図を保ったまま配色を変えて。」

ツール詳細から成果物をプレビュー、保存、共有できます。画像の生成・編集に対応し、API キーモードで GPT Image 2.6 を選ぶと GIF や SVG も依頼できます。GIF・SVG は新規生成のみで、参照画像の編集は PNG になります。利用可能な機能はモデルとサービスに依存します。ノートの結果画像を共有する方法もあります。

「設定 > ツールとスキル > Skills」で ZIP や GitHub から手順を取り込み、有効化して AI に利用を依頼できます。Sandbox は端末上の Linux 環境で、スクリプト、計算、ファイル処理を行います。コマンドの項目から出力の確認や停止が可能です。ターミナルは読み取り専用で、AI サービスとパッケージ取得にはネットワークが必要です。
