# 困ったときは

| 問題 | 確認すること |
| --- | --- |
| AI 整理が始まらない | AI アカウント、iOS の購読、ネットワークを確認して再試行 |
| 録音中の整理がない | iOS で API キーを使用。Codex は保存後の文字起こしに対応 |
| 端末ツールが使えない | データの使用設定、システム権限、プラットフォーム。アラームは iOS 26 以降 |
| アプリ操作が使えない | 対象アプリ、ツールと操作のスイッチ、必須設定 |
| 別の端末で会話ファイルがない | 作業領域は端末内のみ。必要なファイルは書き出し |
| Webページが不完全 | ログイン制限や構造で取得できない場合は、本文やファイルを共有 |
