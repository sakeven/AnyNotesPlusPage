# 파일·이미지·Skills

AI Chat에 자료를 첨부하고 원하는 결과, 형식과 용도를 설명하세요.

{% include guide-screens.html group='outputs' %}

- “이 노트로 프로젝트 브리프를 만들고 결론과 미확인 사항을 공유 가능한 파일에 정리해 줘.”
- “이 데이터의 월별 합계를 계산하고 차트와 결과 파일을 만들어 줘.”
- “처음 접하는 사람을 위한 지식 카드로 이 주제를 설명해 줘.”
- “이 이미지의 내용과 구도를 유지하면서 색상을 바꿔 줘.”

도구 상세에서 결과물을 미리 보고 저장하거나 공유하세요. 이미지 생성과 편집을 지원하며 API 키 모드에서 GPT Image 2.6을 선택하면 GIF와 SVG도 요청할 수 있습니다. GIF와 SVG는 새로 생성할 때만 지원하며 참조 이미지 편집은 PNG로 출력됩니다. 기능은 모델과 서비스에 따라 달라집니다. 노트 결과 이미지를 공유할 수도 있습니다.

**설정 > 도구 및 스킬 > Skills**에서 ZIP이나 GitHub로 작업 지침을 가져와 활성화하고 AI에 사용을 요청하세요. Sandbox는 기기의 Linux 환경으로 스크립트, 계산과 파일 처리를 실행합니다. 명령 활동에서 실제 출력을 보거나 실행을 중지할 수 있습니다. 터미널은 읽기 전용이며 AI 서비스와 패키지 다운로드에는 네트워크가 필요합니다.
