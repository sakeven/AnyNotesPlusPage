# 토픽·Wiki·결과물

{% include guide-screens.html group='topics' %}

1. “다음 출시 계획” 같은 주제를 만들고 관련 노트, 웹페이지, 파일과 녹음을 추가하세요.
2. 현재 관점, 최근 변화, 열린 질문과 다음 단계를 확인하세요. 노트는 한 번에 하나의 주제에 속하며 이동하거나 연결을 해제할 수 있습니다.
3. 방향에 현재 단계, 중요한 질문, 원하는 결과와 이번에 다루지 않을 범위를 적으세요.
4. 자료가 충분하면 Topic Wiki의 초안을 직접 생성하세요. 지식 블록에 출처 노트가 연결되며 기존 Wiki는 새 노트의 처리가 완료되면 갱신됩니다.
5. 브리프, 작업 목록 또는 문서를 생성하세요. 생성이 완료된 결과를 주제의 초안으로 저장하고 준비되면 완료로 표시할 수 있습니다.

> 이 주제의 자료로 세 가지 방안을 비교해 줘. 장점, 비용, 부족한 근거와 다음에 검증할 질문을 정리해 줘.

종합 요약은 현재 진행 상황, Wiki는 축적된 지식, 결과물은 공유하거나 전달할 내용에 적합합니다. 출처는 생성에 사용한 자료를 뜻하며 중요한 결론은 원문과 대조하세요.
