# 실시간 음성 대화

채팅의 음성 진입점에서 양방향 대화를 시작할 수 있습니다. 대화 맥락과 사용 가능한 도구를 이어받고 자막, 음소거, 종료 기능을 제공합니다. 검토가 필요한 작업은 확인 화면을 표시합니다. 음성을 종료하면 받은 대화 기록은 남고 끝나지 않은 요청은 중지됩니다.

{% include guide-screens.html group='voice' %}

1. 홈, 메모, 토픽에서 대화를 열고 실시간 음성 진입점을 선택합니다.
2. 질문을 말하면 자막에 표시됩니다. AI가 답할 때 말을 걸어 중단할 수도 있습니다.
3. 음소거로 마이크를 끄거나 일시 정지한 뒤 준비되면 이어 갑니다.
4. 음성 종료를 선택하고 확인하면 기록이 남아 있는 대화로 돌아갑니다.

> 이 계획을 이어서 이야기하자. 가장 불확실한 가정 두 개를 찾아 하나씩 질문해 줘.

녹음은 내 발화를 노트로 남기는 기능이고 실시간 음성은 AI와 주고받는 대화입니다. 논의를 남기려면 노트 저장 기능을 선택하고 확인하세요. 대화 기록과 첨부 파일은 기기에 저장되며 노트로 저장한 내용은 동기화됩니다.
