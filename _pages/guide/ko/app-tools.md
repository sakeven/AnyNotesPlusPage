# 앱 도구와 단축어

{% include guide-screens.html group='apps' %}

**설정 > 도구 및 스킬 > 앱 도구**에서 연결을 관리하세요. 대상 앱 설치, 도구와 작업 활성화, 필수 설정 입력이 필요합니다.

앱을 연결하려면 AI Chat에서 앱 이름과 원하는 작업을 설명하고 도구 설정 파일을 요청하세요. 생성한 파일을 열어 작업과 설정을 검토한 뒤 설치하고 활성화하세요. 대상 앱이 지원하는 링크나 작업 진입점이 있어야 합니다.

기존 Apple 단축어는 다음과 같이 연결합니다.

1. 시스템 단축어 앱에 설치하고 실행되는지 확인하세요.
2. `.shortcut` 파일을 AnyNotes로 공유하거나 앱 도구에서 가져오세요.
3. 설치된 이름을 확인하고 분석하세요. 용도와 외부 입력을 파악하기 위해 전체 작업 정의가 선택한 AI 서비스로 전송됩니다.
4. 분석 결과를 검토하고 추가·활성화한 뒤 대화에서 이름으로 실행을 요청하세요.

> “읽기 목록 정리” 단축어를 실행하고 방금 이야기한 세 기사를 입력으로 사용해 줘.

가져오기만으로 실행되거나 시스템에 설치되지는 않습니다. 실행 시 확인 절차를 따르며 지원하는 텍스트 결과가 대화로 돌아옵니다. 이름이나 내용을 변경하면 다시 가져오세요. “열림”은 앱으로 이동했다는 뜻이며 결과가 확인되지 않으면 재시도 전에 대상 앱에서 확인하세요.
