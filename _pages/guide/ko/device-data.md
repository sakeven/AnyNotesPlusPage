# 일정·미리 알림·오늘의 진행

iOS의 **설정 > 데이터 사용**에서 AI가 사용할 출처를 허용하세요. 필요할 때 해당 시스템 권한도 요청합니다.

{% include guide-screens.html group='device' %}

- “내일 일정을 확인하고 리뷰 준비 시간을 찾아 줘.”
- “내일 오후 3시에 자료 보내기를 미리 알림에 추가하고 마감 시간에 알려 줘.”
- “방금 찾은 리뷰를 오후 4시로 옮기고 다른 내용은 유지해 줘.”
- “25분 집중 타이머를 시작해 줘.”

일정, 미리 알림과 알람의 쓰기 작업은 대상, 내용, 시간과 알림을 확인한 뒤 반영됩니다. 마감 시간과 알림 시간은 별개이므로 알림이 필요하면 명확히 요청하세요.

오늘의 진행 제안은 노트와 주제 변화, 별도로 사용을 허용한 일정·미리 알림에서 다음에 처리할 항목을 보여 줍니다. 당일 제안을 무시하거나 설정에서 표시를 끌 수 있습니다.

일정과 미리 알림은 한 번에 최대 31일을 조회하며 미리 알림 조회는 미완료 항목을 대상으로 합니다. 알람은 AnyNotes가 만든 항목만 접근하며 시스템 시계 앱의 알람은 읽지 못합니다. 사진 검색은 허용 범위, 날짜와 문자 인식을 사용합니다. 건강은 걸음 수, 수면과 운동 기록 읽기만 지원합니다. 위치는 앱이 앞에 있을 때 한 번 가져옵니다. 건강 데이터가 포함된 대화는 동기화되는 노트로 저장할 수 없습니다.
