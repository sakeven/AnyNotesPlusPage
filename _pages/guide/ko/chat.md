# AI 텍스트 대화

홈에서 독립 대화를 시작하거나 노트와 주제에서 맥락이 포함된 대화를 여세요. 첨부 파일 추가, 보낸 질문 편집, 응답 중지, 로컬 기록에서 대화 재개를 지원합니다.

{% include guide-screens.html group='chat' %}

녹음은 내 발화를 노트로 남기는 기능이고 실시간 음성은 AI와 주고받는 대화입니다. 논의를 남기려면 노트 저장 기능을 선택하고 확인하세요. 대화 기록과 첨부 파일은 기기에 저장되며 노트로 저장한 내용은 동기화됩니다.
