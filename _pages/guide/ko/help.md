# 문제 해결

| 문제 | 확인할 항목 |
| --- | --- |
| AI 정리가 시작되지 않음 | AI 계정, iOS 구독, 네트워크를 확인한 뒤 재시도 |
| 녹음 중 실시간 정리가 없음 | iOS에서 API 키 사용. Codex는 저장 후 전사를 지원 |
| 기기 도구를 사용할 수 없음 | 데이터 사용 설정, 시스템 권한, 플랫폼. 알람은 iOS 26 이상 |
| 앱 작업을 사용할 수 없음 | 대상 앱, 도구·작업 스위치, 필수 설정 |
| 다른 기기에 채팅 파일이 없음 | 작업 공간은 로컬 저장. 필요한 파일은 내보내기 |
| 웹페이지 내용이 불완전함 | 로그인 제한이나 페이지 구조가 원인일 수 있으므로 원문이나 파일을 공유 |

[지원 페이지]({{ '/ko/support/' | relative_url }})를 확인하거나 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com)으로 문의하세요. 플랫폼, 버전, 재현 단계와 오류 메시지를 함께 보내면 확인에 도움이 됩니다.
