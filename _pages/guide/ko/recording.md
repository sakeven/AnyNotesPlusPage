# 녹음과 실시간 정리

{% include guide-screens.html group='recording' %}

1. 녹음을 시작하세요. 특정 프로젝트의 자료라면 해당 주제 안에서 시작하세요.
2. API 키 모드에서는 **실시간 정리**와 전사 원문을 전환하며 핵심 내용, 열린 질문과 다음 단계를 확인할 수 있습니다.
3. **생각 도와주기**로 제안을 요청하세요. AI 제안과 원문은 따로 표시되며 녹음 중 정리는 임시 결과입니다.
4. 제안된 작업을 검토하면 녹음이 일시 정지됩니다. 제목, 날짜, 알림이나 앱 작업을 편집하고 확인한 뒤 실행하세요.
5. 수동으로 녹음을 재개하거나 완료하여 저장하세요. 저장 후에도 전체 녹음을 전사하고 정리합니다.

> 이 논의의 결정 사항, 해결되지 않은 질문과 실행 항목을 정리해 줘. 담당자는 명시된 경우에만 넣어 줘.

실시간 정리에는 API 키가 필요합니다. Codex 로그인에서도 녹음과 저장 후 전사는 가능합니다. 연결이 끊어지면 녹음 화면에서 다시 연결하고 전사 진행 상태를 확인하세요. 제안이 보이거나 녹음을 완료하는 것만으로 작업이 실행되지는 않습니다. 이미 확인해 실행한 외부 작업은 녹음을 취소해도 되돌아가지 않습니다.
