# 產生檔案、圖片與 Skills

把附件放入 AI 對話，明確告訴 AI 想要的結果、格式和用途。

{% include guide-screens.html group='outputs' %}

- 「根據這些筆記做一份項目簡報，列出結論和待確認事項，生成可分享的檔案。」
- 「讀取這個資料檔案，算出每月總量並畫圖，把結果檔案給我。」
- 「把這個主題解釋成一張知識卡片，適合發給第一次接觸它的人。」
- 「基於這張圖片修改配色，保留主要內容和構圖。」

生成檔案和圖片可以從工具詳情中預覽、儲存或分享。AI Chat 支援圖片生成與編輯；API Key 模式選擇 GPT Image 2.6 後還可請求 GIF 或 SVG。GIF 和 SVG 僅支援新生成，參考圖編輯輸出 PNG；具體能力取決於所選模型與服務。筆記的結果分享圖也可直接用於分享整理內容。

在「設定 > 工具與技能 > Skills」從 ZIP 或 GitHub 匯入可復用的工作步驟，啓用後讓 AI 在任務中使用。Sandbox 提供裝置端 Linux 環境，用於腳本、計算和檔案處理；點擊命令活動可查看真實輸出或停止命令，終端面板只讀。AI 服務和軟件包下載需要網絡。
