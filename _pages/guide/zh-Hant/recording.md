# 錄音與即時整理

適合項目討論、採訪、學習復述，也適合一個人把零散想法說清楚。

{% include guide-screens.html group='recording' %}

1. 點擊「錄音」。如果材料屬於一個項目，可以先進入對應主題再開始。
2. API Key 模式下，可在「即時整理」與「轉寫內容」之間切換，邊說邊看要點、尚未想清楚的問題和下一步。
3. 需要啓發時點「幫我想想」。AI 的建議與轉錄原文分開展示，臨時整理仍需要你核對。
4. 出現「可選操作」時，先點「檢視並確認」。錄音會暫停，你可以修改標題、時間、通知或App 操作內容，確認後才會執行。
5. 返回後手動繼續錄音，或點擊「完成」儲存。完成後仍會根據完整錄音轉寫和整理。

**儲存後可以這樣提問：**

> 根據這次討論，列出已經決定的事項、還需要確認的問題，以及每項行動中明確提到的負責人。沒有提到的不要補寫。

即時整理目前需要 API Key；Codex 登入仍可錄音並在儲存後轉寫。網絡斷開時可在錄音頁重新連接，並查看已轉錄進度。日程、提醒或 App 操作不會因為建議出現或錄音完成就自動執行；已經確認執行的外部操作不會隨取消錄音而撤銷。
