# 常見問題

| 問題 | 可以檢查什麼 |
| --- | --- |
| AI 沒有開始整理 | 檢查 AI 服務帳號、iOS 訂閱和網絡，再從失敗項重試 |
| 錄音中沒有即時整理 | 確認在 iOS 使用 API Key；Codex 登入仍支援儲存後轉寫 |
| 裝置工具不可用 | 檢查「資料使用」、系統權限和平台；鬧鐘需要 iOS 26 |
| App 操作不可用 | 檢查目標 App、工具總開關、操作開關及必填配置 |
| 新裝置沒有聊天檔案 | 聊天工作區僅儲存在本機；需要的檔案應先匯出 |
| 網頁內容不完整 | 登入限制或頁面結構可能影響提取，可補充分享原文或檔案 |

更多問題請查看[支援頁面]({{ '/zh-Hant/support/' | relative_url }})，或聯繫 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com)。反饋時可附上平台、版本、操作步驟與錯誤提示。
