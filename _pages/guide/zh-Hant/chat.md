# AI 文字對話

從首頁開始獨立對話，或從筆記、主題的「深入探討」進入帶上下文的對話。支援附加材料、編輯已發送的問題、停止回復，以及從本機歷史中繼續之前的討論。

{% include guide-screens.html group='chat' %}

「錄音」適合儲存自己的講話並形成筆記；「即時語音」適合與 AI 來回討論。需要把討論沈澱下來時，使用對話中的儲存筆記入口並確認。對話歷史和附件在本機儲存，儲存成筆記的內容才進入筆記同步。
