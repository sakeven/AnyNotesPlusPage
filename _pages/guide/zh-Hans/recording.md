# 录音与实时整理

适合项目讨论、采访、学习复述，也适合一个人把零散想法说清楚。

{% include guide-screens.html group='recording' %}

1. 点击「录音」。如果材料属于一个项目，可以先进入对应主题再开始。
2. API Key 模式下，可在「实时整理」与「转写稿」之间切换，边说边看要点、尚未想清楚的问题和下一步。
3. 需要启发时点「帮我想想」。AI 的建议与转录原文分开展示，临时整理仍需要你核对。
4. 出现「可选操作」时，先点「查看并确认」。录音会暂停，你可以修改标题、时间、通知或应用操作内容，确认后才会执行。
5. 返回后手动继续录音，或点击「完成」保存。完成后仍会根据完整录音转写和整理。

**保存后可以这样提问：**

> 根据这次讨论，列出已经决定的事项、还需要确认的问题，以及每项行动中明确提到的负责人。没有提到的不要补写。

实时整理目前需要 API Key；Codex 登录仍可录音并在保存后转写。网络断开时可在录音页重新连接，并查看已转录进度。日程、提醒或 App 操作不会因为建议出现或录音完成就自动执行；已经确认执行的外部操作不会随取消录音而撤销。
