# 生成文件、图片与 Skills

把附件放入 AI 对话，明确告诉 AI 想要的结果、格式和用途。

{% include guide-screens.html group='outputs' %}

- 「根据这些笔记做一份项目简报，列出结论和待确认事项，生成可分享的文件。」
- 「读取这个数据文件，算出每月总量并画图，把结果文件给我。」
- 「把这个主题解释成一张知识卡片，适合发给第一次接触它的人。」
- 「基于这张图片修改配色，保留主要内容和构图。」

生成文件和图片可以从工具详情中预览、保存或分享。AI Chat 支持图片生成与编辑；API Key 模式选择 GPT Image 2.6 后还可请求 GIF 或 SVG。GIF 和 SVG 仅支持新生成，参考图编辑输出 PNG；具体能力取决于所选模型与服务。笔记的结果分享图也可直接用于分享整理内容。

在「设置 > 工具与技能 > Skills」从 ZIP 或 GitHub 导入可复用的工作步骤，启用后让 AI 在任务中使用。Sandbox 提供设备端 Linux 环境，用于脚本、计算和文件处理；点击命令活动可查看真实输出或停止命令，终端面板只读。AI 服务和软件包下载需要网络。
