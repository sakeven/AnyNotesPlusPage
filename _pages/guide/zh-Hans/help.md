# 常见问题

| 问题 | 可以检查什么 |
| --- | --- |
| AI 没有开始整理 | 检查 AI 服务账号、iOS 订阅和网络，再从失败项重试 |
| 录音中没有实时整理 | 确认在 iOS 使用 API Key；Codex 登录仍支持保存后转写 |
| 设备工具不可用 | 检查「数据使用」、系统权限和平台；闹钟需要 iOS 26 |
| App 操作不可用 | 检查目标 App、工具总开关、操作开关及必填配置 |
| 新设备没有聊天文件 | 聊天工作区仅保存在本机；需要的文件应先导出 |
| 网页内容不完整 | 登录限制或页面结构可能影响提取，可补充分享原文或文件 |

更多问题请查看[支持页面]({{ '/zh-Hans/support/' | relative_url }})，或联系 [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com)。反馈时可附上平台、版本、操作步骤与错误提示。
