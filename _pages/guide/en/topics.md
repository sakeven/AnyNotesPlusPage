# Topics, Wiki & outcomes

Use Topics for product planning, reading, courses, or ongoing projects.

{% include guide-screens.html group='topics' %}

1. Create a Topic such as “Next release planning” and add relevant text, web pages, files, and recordings.
2. Review its current view, recent changes, open questions, and next moves. A note belongs to one Topic at a time and can be moved or removed.
3. Set a **Direction**: the current stage, what matters most, the result you want, and what is outside the current scope.
4. When enough material is ready, generate the first **Topic Wiki**. It organizes knowledge into blocks with source notes. An existing Wiki updates as new notes finish processing.
5. Generate a brief, task list, or full draft when you need a deliverable. Save a completed generation as a Topic draft, then mark it completed when ready.

**Try this:**

> Compare three options using the material in this Topic. List benefits, costs, missing evidence, and the questions we should test next.

The synthesis tracks current progress, the Wiki accumulates knowledge, and outcomes hold deliverables. Source links show material used during generation; check important conclusions against the originals.
