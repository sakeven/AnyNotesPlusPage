# Troubleshooting

| Problem | What to check |
| --- | --- |
| AI processing does not start | AI account, iOS subscription, and network; then retry the failed item |
| No live recording insights | Use API-key mode on iOS; Codex still supports transcription after saving |
| Device tool unavailable | Data Usage settings, system permissions, and platform; alarms need iOS 26 |
| App action unavailable | Target app, tool and action switches, and required configuration |
| Missing chat files on another device | Workspaces are local; export files you want to move |
| Incomplete web page content | Login restrictions or page structure may prevent extraction; share the text or a file instead |

See [Support]({{ '/support/' | relative_url }}) or email [sakeven.jiang@gmail.com](mailto:sakeven.jiang@gmail.com). Include the platform, app version, steps, and error message when reporting a problem.
