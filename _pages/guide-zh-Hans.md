# 快速上手

1. 打开 AnyNotes+，用首页的「笔记」写下一个想法并保存。
2. 在「设置 > AI 服务」配置自己的 OpenAI API Key，或使用 Codex 登录。iPhone、iPad 的 AI 功能还需要 AnyNotes Pro。
3. 回到笔记，查看 AI 整理后的标题、摘要、结果和建议下一步。保存原始内容与 AI 整理是分开的，整理失败时可以稍后重试。
4. 点击「深入探讨」，带着这条笔记的上下文继续对话。
5. 如果还有相关材料，把它加入一个主题，后续笔记也归入同一主题。

| 平台或服务 | 使用条件 |
| --- | --- |
| iPhone / iPad | AI 功能需要 AnyNotes Pro，以及有效的 API Key 或 Codex 登录 |
| Mac | 无需 AnyNotes Pro；AI 功能仍需配置账号 |
| 录音实时整理 | iOS，API Key 模式，需要支持实时转录的服务与网络 |
| 日历、提醒、照片、健康和位置工具 | iOS，按来源授权；闹钟与倒计时需要 iOS 26 或更新版本 |

AnyNotes Pro 与 AI 服务用量是分开的。TestFlight 中的测试订阅免费，也不代表所配置 AI 服务的用量免费。模型和部分能力取决于账号及服务支持情况。
