# 快速上手

1. 打開 AnyNotes+，用首頁的「筆記」寫下一個想法並儲存。
2. 在「設定 > AI 服務」配置自己的 OpenAI API Key，或使用 Codex 登入。iPhone、iPad 的 AI 功能還需要 AnyNotes Pro。
3. 回到筆記，查看 AI 整理後的標題、摘要、結果和建議下一步。儲存原始內容與 AI 整理是分開的，整理失敗時可以稍後重試。
4. 點擊「深入探討」，帶著這條筆記的上下文繼續對話。
5. 如果還有相關材料，把它加入一個主題，後續筆記也歸入同一主題。

| 平台或服務 | 使用條件 |
| --- | --- |
| iPhone / iPad | AI 功能需要 AnyNotes Pro，以及有效的 API Key 或 Codex 登入 |
| Mac | 無需 AnyNotes Pro；AI 功能仍需配置帳號 |
| 錄音即時整理 | iOS，API Key 模式，需要支援即時轉錄的服務與網絡 |
| 行事曆、提醒、照片、健康和位置工具 | iOS，按來源授權；鬧鐘與倒計時需要 iOS 26 或更新版本 |

AnyNotes Pro 與 AI 服務用量是分開的。TestFlight 中的測試訂閱免費，也不代表所配置 AI 服務的用量免費。模型和部分能力取決於帳號及服務支援情況。
